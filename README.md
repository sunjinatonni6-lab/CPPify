# Cppify - WebAssembly C++ Compiler Studio

## Files
- `index.html` — page structure and UI
- `styles.css` — custom CSS styles
- `app.js` — app behavior, tokenization, WebAssembly generation, execution and export
- `tailwind.config.js` — Tailwind theme extension

## Run
Open `index.html` in a modern browser. Internet access is required for the Tailwind CSS CDN, Font Awesome and Google Fonts.

## Notes
This is a browser-side educational compiler demo for the supported `std::cout` string-buffer pattern and `add`, `sub`, `mult`, `div` integer operations. It is not a complete C++ compiler and does not compile arbitrary C++ source.
